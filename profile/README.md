# Tempora

**A native macOS app for organizing and managing your time.**

Tempora turns the hours you actually work into clean, organized records — with almost no manual bookkeeping. It runs as both a main window and a menu-bar app, tracks the apps and windows you use automatically, lays your day out on a visual color-coded timeline, and can push tracked time straight to Jira issues as worklogs. Your data stays on your Mac.

![Tempora's Activities view — the day laid out on a color-coded timeline above the list of time entries and automatically tracked app activity](https://raw.githubusercontent.com/Tempora-Time-Tracking/tempora-releases/main/Activities.jpg)

## Highlights

- **Automatic activity tracking** — Tempora records the apps and windows you use, so your day is already mapped before you touch anything.
- **Visual timeline** — see the day laid out as a color-coded timeline above your time entries.
- **Scheduled timers & presets** — plan work ahead and start recurring tasks in one click.
- **Jira worklogs** — push tracked time straight to Jira issues, with reminders so nothing slips.
- **Calendar overlay** — see your calendar events alongside what you actually worked on.
- **Private by default** — your data stays on your Mac.

Requires **macOS 15 (Sequoia) or later**. The app is signed with a Developer ID and notarized by Apple. Tempora keeps itself up to date automatically.

Key changes from the releases README, and why:

- Absolute image URL — a profile README lives in a different repo than Activities.jpg, so the relative path would 404. I pointed it at the raw file in tempora-releases.
- Download link → repo, not a pinned .dmg — the releases README hard-codes 0.4/Tempora-0.4.dmg, which you'd have to bump every release. On the org profile you don't want to re-edit it each time, so it links to the releases repo where the current download always lives.
- Dropped repo plumbing — the "What's in this repository" table and appcast.xml/.zip details are meaningless on an org profile page, so they're gone; added a short Highlights list instead.
